# BlenderKit mannequins

Male and female Rigify mannequins by **Fasolka 3D**, downloaded from BlenderKit
on 2026-10-31. Original Blender files and BlenderKit's glTF exports are preserved.

| Character | Blender source | Self-contained glTF |
| --- | --- | --- |
| [Male](https://www.blenderkit.com/asset-gallery-detail/7a5aeacf-d088-423e-916c-f9bbdfdb9306/) | `male/mannequin_male.blend` | `male/mannequin_male.glb` |
| [Female](https://www.blenderkit.com/asset-gallery-detail/cd637167-44db-4503-a1cd-47f9900b7747/) | `female/mannequin_female.blend` | `female/mannequin_female.glb` |

Each `source.json` records the upstream asset/version identifiers, author,
license label, file sizes and SHA-256 hashes. Both GLBs contain one skinned mesh,
400 joints and one animation, with no external buffer or image references.
The exports retain Rigify's control/helper bones; they have not yet been
integrated into Citrus's starter templates or visually tested in the engine.
